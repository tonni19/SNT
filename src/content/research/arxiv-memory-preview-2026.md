An assistant that remembers needs a rule for when it may reuse a memory, and an editor can confirm a rule by previewing one use it allows and one it blocks. This work enumerates every rule compatible with such a preview, measures what stays ambiguous, and tests which follow-up requests resolve it. A small pilot survey checks whether people can predict what the rule they saved will do.

## What's in the repository

The code, fixtures, results and the survey behind the paper: the permission gate and fictional scenarios, the analysis scripts with every result file the paper reports, the LaTeX source, the prototype memory editor and diagnostic, and the pilot survey program. All scenarios are fictional and no identifying information was collected.
